Credits & licences

Tumble Grove is an independent fruit-dropping game, made for your happy little breaks.

Fruit, sound and interface

The fruit illustrations were generated for this project using OpenAI image generation. Short sound effects are synthesised in your browser. Text and fallback emoji use fonts already available on your device.

Interface components and styles include shadcn/ui, Base UI and Tailwind CSS. Icons come from Lucide, including icons derived from Feather. The game also uses React and other libraries credited below.
